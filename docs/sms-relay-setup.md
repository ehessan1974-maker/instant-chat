# دليل تفعيل بوابة SMS (Relay) — إرسال رموز الدخول من هاتفك الأندرويد

> هذه البوابة تجعل تطبيق «محادثة فورية» يرسل رموز الدخول كرسائل SMS **من شريحة هاتفك**،
> بلا أي مزود خارجي مدفوع — التكلفة الوحيدة هي رسائل باقتك.

## لماذا Relay؟ (المقارنة)

| الخيار | الحكم | السبب |
|---|---|---|
| **بوابة Relay (هاتف أندرويد)** | ⭐ الأنسب لسوريا | مجاني تماماً، يعمل مع أي رقم سوري، بلا طرف ثالث |
| WhatsApp Business API | ❌ محجوب | ميتا تحظر رسمياً إرسال الرسائل **إلى/من سوريا** (نفس سبب حظر Twilio) — والحلول غير الرسمية تعرّض الرقم للحظر |
| Twilio SMS | ❌ محجوب | لا يدعم سوريا منذ 9/2025 |
| مزود HTTP مدفوع (Unimatrix وغيره) | ✅ يعمل | تكلفة لكل رسالة + تسجيل وتعبئة رصيد |
| Vonage | ✅ يعمل | تكلفة لكل رسالة + تسجيل |

## المتطلبات

1. هاتف **أندرويد** فيه شريحة SMS نشطة (بها باقة رسائل).
2. تطبيقان من **F-Droid** (مهم: نسختان متطابقتان من نفس المصدر — لا تخلط مع Play Store أو GitHub):
   - تطبيق F-Droid نفسه (إن لم يكن مثبتاً): <https://f-droid.org/F-Droid.apk>
   - [Termux — صفحة التحميل](https://f-droid.org/packages/com.termux/) أو APK مباشر: <https://f-droid.org/repo/com.termux_1022.apk>
   - [Termux:API — صفحة التحميل](https://f-droid.org/packages/com.termux.api/) أو APK مباشر: <https://f-droid.org/repo/com.termux.api_1002.apk>
   - الترتيب مهم: ثبّت **Termux أولاً** ثم **Termux:API**.
3. عنوان سيرفر Render: `https://instant-chat-f2ac.onrender.com`
4. رمز سري `SMS_RELAY_TOKEN` (ولّدناه سابقاً — يُضبط على Render وعلى الهاتف فقط ولا يُكتب في أي مستودع).

## الخطوة 1 — متغيرات البيئة على Render

افتح لوحة Render → خدمة instant-chat → **Environment** وأضف (أو تأكد من وجود):

| المتغير | القيمة | الغرض |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت `8886093644:AAG...` | قناة تيليجرام الافتراضية |
| `TELEGRAM_BOT_USERNAME` | `instant_chat_otp_bot` | اسم المستخدم لبناء رابط الاستلام |
| `SMS_PROVIDER` | `relay` | تفعيل بوابة الموبايل لمسار SMS |
| `SMS_RELAY_TOKEN` | *(الرمز السري الذي ولّدناه)* | مصادقة الهاتف عند السحب والإثبات |

ثم اضغط **Save Changes** → **Manual Deploy** → **Deploy latest commit**.

> ملاحظة: ما دام `TELEGRAM_BOT_TOKEN` مضبوطاً فالافتراضي هو تيليجرام،
> ومسار SMS (بوابة Relay) يُستخدم لمن لا يملك تيليجرام عبر زر
> «لا تملك تيليجرام؟ استلم الرمز برسالة نصية SMS» في شاشة الدخول.

## الخطوة 2 — تجهيز الهاتف (Termux)

في هاتف الأندرويد:

1. ثبّت **Termux** و **Termux:API** من F-Droid (لا تستخدم نسخة Play Store المتهالكة).
2. افتح Termux ونفّذ مرة واحدة:
   ```bash
   pkg update -y && pkg install -y termux-api jq curl
   ```
3. حمّل السكربت من سيرفرك مباشرة:
   ```bash
   curl -O https://instant-chat-f2ac.onrender.com/relay-sms.sh
   chmod +x relay-sms.sh
   ```
4. مرّر الرمز السري وأشغّل البوابة:
   ```bash
   export SMS_RELAY_TOKEN="ضع_الرمز_السري_هنا"
   termux-wake-lock
   ./relay-sms.sh
   ```
   - عند أول إرسال سيطلب أندرويد صلاحية إرسال SMS — وافق عليها.
   - السطر `termux-wake-lock` يمنع النظام من إسبات السكربت.

**لإبقاء البوابة تعمل بعد إغلاق الشاشة (بالخلفية):**
```bash
termux-wake-lock && nohup ./relay-sms.sh > relay.log 2>&1 &
```

**نصائح استقرار مهمة:**
- من إعدادات أندرويد: عطّل **تحسين البطارية** لتطبيق Termux (Settings → Battery → Termux → Unrestricted).
- إن أردت تشغيله تلقائياً عند إقلاع الهاتف ثبّت إضافة **Termux:Boot** وأضف السطر السابق في `~/.termux/boot/start-relay.sh`.

## الخطوة 3 — التأكد أن كل شيء يعمل

1. من متصفح آخر (أو هاتف آخر) افتح الموقع وادخل رقماً **لا يملك تيليجرام**.
2. اضغط «إرسال رمز التحقق» ثم زر البديل «استلم الرمز برسالة نصية SMS».
3. خلال ثوانٍ (السحب كل 5 ثوانٍ) يجب أن يصلك SMS بنص مثل:
   `رمز الدخول لمحادثة فورية: 4821`
4. في Termux سترى سطوراً مثل:
   ```
   [relay] إرسال إلى +9639xxxxxxxx ...
   [relay] ✓ أُرسلت (clx...)
   ```

## كيف تعمل البوابة؟ (التدفق الكامل)

```
المستخدم يطلب رمزاً (بلا تيليجرام)
        │
        ▼
POST /api/auth/request-otp  ──►  يُنشأ رمز مخفي + صف في جدول SmsOutbox (status: pending)
        │                          الاستجابة: { delivered: true } — الرمز لا يُكشف أبداً
        ▼
هاتفك (relay-sms.sh) يسحب كل 5 ثوانٍ:
GET /api/sms/relay/pending?limit=5   (Authorization: Bearer SMS_RELAY_TOKEN)
        │
        ▼
termux-sms-send يرسل الرسالة من شريحتك
        │
        ▼
POST /api/sms/relay/confirm  { results:[{ id, ok, error }] }
```

**ضمانات مدمجة في الخادم:**
- مصادقة Bearer إلزامية — بلا `SMS_RELAY_TOKEN` صحيح: 401.
- كل رسالة تُسحب حتى 3 مرات كحد أقصى؛ إن لم تُثبَّت تُسقط تلقائياً (`dropped`) فلا تكرار لا نهائي.
- كولداون دقيقة لكل رقم + سقف 8 رموز/ساعة لكل رقم + سقف 60/ساعة عام يحمي باقتك.
- الرمز الحقيقي لا يعود في أي استجابة API إطلاقاً — يصل فقط في الرسالة النصية.

## استكشاف الأخطاء

| العرض | السبب المحتمل | الحل |
|---|---|---|
| `401 UNAUTHORIZED` في السكربت | `SMS_RELAY_TOKEN` على الهاتف لا يطابق Render | قارن القيمتين حرفياً |
| `{error: RELAY_DISABLED}` (404) | `SMS_RELAY_TOKEN` غير مضبوط على Render أو نشر قديم | أضف المتغير ثم Manual Deploy |
| الرسائل لا تصلك والمستخدم ينتظر | صلاحية SMS غير ممنوحة / النظام أنام السكربت | امنح الصلاحية، `termux-wake-lock`، عطّل تحسين البطارية |
| `termux-sms-send: command not found` | حزمة termux-api غير مثبتة | `pkg install -y termux-api` (وTermux:API من F-Droid) |
| وصل SMS مكرر لنفس الرمز | السحب تم ولم يُثبَّت (قطع شبكة) | طبيعي — يُصلح تلقائياً بعد confirm، والحد 3 محاولات يمنع الطوفان |
