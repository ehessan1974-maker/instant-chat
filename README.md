# 💬 محادثة فورية — Instant Chat v3

تطبيق محادثة فورية عربي (RTL) بأسلوب واتساب: هوية فريدة برقم الهاتف، محادثات خاصة 1:1، **مجموعات** تنشئها وتدعو إليها بنفسك، **رسائل صوتية**، و**مكالمات صوت وفيديو** (WebRTC)، مع مؤشرات ✓/✓✓ للحالة والحضور والكتابة، وقاعدة بيانات دائمة.

> **الإصدار 3.0** — تحوّل كامل من «غرفة عامة» إلى نظام هويات ومجموعات حقيقي مثل واتساب. الإصدار 2.0 نفسه كان إعادة بناء كاملة عن النسخة القديمة (Express + ws خام) المحفوظة للمرجعية في [`legacy/`](./legacy).

> **🧭 للمطوّر / لاستئناف العمل:** حالة المشروع الحالية وخطوات العودة موثقة في [`docs/PROJECT_STATE.md`](./docs/PROJECT_STATE.md)، وسجل المهام التفصيلي في [`docs/DEVELOPMENT_LOG.md`](./docs/DEVELOPMENT_LOG.md). الإصدار الحالي: **v2.4** (شارة ظاهرة في شاشة الدخول).

## 🏗️ البنية التقنية

```
المتصفح (Next.js + React + Tailwind + shadcn/ui)
   │  REST: /api/auth، /api/users، /api/conversations، /api/media/voice…
   │  Socket.IO: رسائل وصوتيات + مجموعات + حضور + تأشير مكالمات WebRTC
   ▼
Next.js (:3000) ──────────────┐
                              │ نفس قاعدة SQLite (WAL)
خدمة المحادثة chat-service ───┘
(Socket.IO على :3003، Prisma)
   │
   ├─ عملاء الويب: بروتوكول «الجلسات» (token → auth)
   │    • رسائل نصية وصوتية، إنشاء/إضافة/مغادرة مجموعات
   │    • تأشير المكالمات: call_invite/accept/offer/answer/ice/end
   └─ عملاء APK القديمون: بروتوكول legacy (login بالاسم كوسيط نصي)
        بأشكال الأحداث القديمة حرفياً: your_info / previous_messages /
        online_users / user_joined / user_left / new_message / user_typing
```

- **الواجهة**: `src/` — Next.js 16 App Router + TypeScript + Tailwind 4 + shadcn/ui
- **REST API**: `src/app/api/**` — مصادقة OTP، مستخدمون، محادثات، رسائل، ملفات صوتية (ترحيل للرسائل الأقدم)
- **خدمة السوكيت**: `mini-services/chat-service/` — Socket.IO + Prisma، منفذ `3003` (قابل للتغيير بـ `CHAT_PORT`)
- **قاعدة البيانات**: SQLite + WAL مشتركة بين الطرفين عبر `DATABASE_URL`

### كيف تعمل الميزات الجديدة؟
- **الرسائل الصوتية**: يُسجّل الصوت في المتصفح بـ MediaRecorder (webm/opus)، يُرسل base64 عبر السوكيت (حد 10MB)، يُخزّن كملف في `db/voice/` باسم UUID ويُخدم عبر `/api/media/voice/<file>` بدعم Range.
- **المكالمات**: تأشير (signaling) عبر Socket.IO فقط — الوسائط تذهب مباشرة بين المتصفحين عبر WebRTC (STUN من Google). يدعم تعدد الأجهزة لنفس الحساب (الرد من جهاز يلغي الرنين على البقية).
- **المجموعات**: أحداث `create_group` / `add_members` / `leave_group` مع رسائل نظام وبث حي (`group_created` / `group_members_changed` / `group_left`) لكل الأعضاء.

### ملاحظة توافق الـ APK المهمة
سيرفر السوكيت يعمل بمسار `/`، ومحرك engine.io يطابق المسار **بالبادئة**، لذلك يقبل السيرفر أيضاً المسار الافتراضي `/socket.io` الذي يستخدمه الـ APK القديم — سيرفر واحد يخدم الجميع دون إعدادات إضافية.

## 🚀 التشغيل محلياً

المتطلبات: Node 20+ أو Bun، وأحد مديري الحزم npm/pnpm/bun.

```bash
# 1) الواجهة + REST API
cp .env.example .env          # ثم عدّل DATABASE_URL إلى مسار مطلق
npm install
npx prisma db push            # إنشاء قاعدة البيانات
npm run dev                   # http://localhost:3000

# 2) خدمة السوكيت (نافذة طرفية ثانية)
cd mini-services/chat-service
cp .env.example .env          # نفس DATABASE_URL النسخة السابقة بالضبط
npm install
npx prisma generate
npm run dev                   # يستمع على 3003
```

افتح `http://localhost:3000`، أدخل أي رقم هاتف، سيظهر **رمز التحقق في الواجهة** (وضع تجريبي بلا مزود SMS)، ثم اسمك — وأنت داخل.

### ملف `.env` (الجذر)

```bash
# قاعدة البيانات — استخدم مساراً مطلقاً
DATABASE_URL=file:/absolute/path/to/project/db/custom.db

# اتصال السوكيت من المتصفح — اختر حالة واحدة:
# أ) نشر خلف وكيل يمرر /socket.io إلى :3003 (موصى به للإنتاج)
NEXT_PUBLIC_SOCKET_URL=
NEXT_PUBLIC_SOCKET_PATH=/socket.io
# ب) اتصال مباشر بدون وكيل (كورس مفتوح في الخدمة أصلًا)
# NEXT_PUBLIC_SOCKET_URL=http://SERVER_IP:3003
# NEXT_PUBLIC_SOCKET_PATH=/socket.io
# ج) بيئة بوابة Caddy بشكل هذه البيئة التجريبية
# NEXT_PUBLIC_SOCKET_URL=/?XTransformPort=3003
# NEXT_PUBLIC_SOCKET_PATH=/
```

### ملف `mini-services/chat-service/.env`

```bash
DATABASE_URL=file:/absolute/path/to/project/db/custom.db   # نفس القيمة السابقة
# CHAT_PORT=3003                                            # اختياري
```

## 🌐 النشر على سيرفر (VPS)

الطريقة الموصى بها (دومين واحد + nginx):

1. شغّل الواجهة على `127.0.0.1:3000` (بعد `npm run build && npm run start` أو عبر pm2/systemd).
2. شغّل خدمة السوكيت على `127.0.0.1:3003`.
3. في nginx، مرّر `/socket.io` إلى خدمة السوكيت مع ترويسات الترقية:

```nginx
location /socket.io/ {
    proxy_pass http://127.0.0.1:3003;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
}
location / {
    proxy_pass http://127.0.0.1:3000;
}
```

4. فعّل شهادة HTTPS (certbot) — **ضرورية لإشعارات Push مستقبلاً**.

> ℹ️ **APK v4.0 لا يستخدم WebSocket مباشرة إطلاقاً** — واجهته تفتح صفحات الخادم (كاملة أو خفيفة) عبر HTTPS، لذا لا قيود ws:// قديمة عليه. النسخة الخفيفة legacy.html تعمل بـ REST فقط على أقدم WebView.

### 📱 تطبيق الأندرويد (v4.0)
`android/InstantChat.apk` — واجهة إطلاق ذكية ES5: يفحص قدرات WebView عند الإقلاع — الجهاز الحديث يفتح **التطبيق الكامل** (مجموعات/محادثات خاصة/صوتيات/مكالمات)، والقديم يفتح النسخة الخفيفة تلقائياً. الخادم مضمّن (Render) والافتتاح ذاتي، مع إعدادات كاملة (ضغطة طويلة على الشعار أو «إلغاء» أثناء الافتتاح) لتغيير الخادم أو وضع الفتح. الدخول محفوظ تلقائياً بعد أول مرة. يعمل على أي أندرويد ≥ 4.4.

> ⚠️ **ملاحظة تثبيت**: النسخة الحالية موقّعة بمفتاح جديد — من ركّب نسخة أقدم يجب أن يحذفها أولاً (مرة واحدة فقط).
>
> 🔐 **للمالك**: مفتاح التوقيع وسكربتات البناء خارج الريبو في `.apk-signing/` — انسخها احتياطياً (التفاصيل والخطوات في `.apk-signing/README.md`).

### 📨 رمز الدخول: قناة تيليجرام (موصى بها — مجانية 100% وبلا أجهزة)
أنشئ بوتاً مرة واحدة من تيليجرام (ابحث عن `@BotFather` → أرسل `/newbot`) ثم اضبط:

| المتغير | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من BotFather |
| `TELEGRAM_BOT_USERNAME` | يوزر البوت بدون `@` |

عند تفعيلها تصبح قناة التسليم الأولى: المستخدم يضغط زر «استلم الرمز عبر تيليجرام» فيصفله البوت فوراً ويرسل له الرمز — بلا SMS وبلا أي تكلفة. البوت يعمل داخل نفس الخادم (long polling — لا منفذ إضافي) ويجيب من تلقاء نفسه على أي رسالة ترحيبية.

### 📱 رمز الدخول SMS حقيقي (اختياري)
بشكل افتراضي يعمل التطبيق بوضع تجريبي: رمز الدخول يظهر في الواجهة نفسها. لتشغيل إرسال رمز حقيقي بالرسائل النصية، اضبط متغيرات البيئة:

| المتغير | القيمة |
|---|---|
| `SMS_PROVIDER` | `twilio` أو `vonage` أو `http` (فارغ = وضع تجريبي) |
| `SMS_PROVIDER=twilio` | + `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM` — **لا يدعم سوريا منذ 9/2025** |
| `SMS_PROVIDER=vonage` | + `VONAGE_API_KEY`, `VONAGE_API_SECRET`, `VONAGE_FROM` |
| `SMS_PROVIDER=http` | + `SMS_HTTP_URL` (POST JSON `{to, message}`), `SMS_HTTP_TOKEN` اختياري — يناسب أي مزود يدعم أرقام سوريا |
| `SMS_PROVIDER=relay` | + `SMS_RELAY_TOKEN` — **بلا تكلفة**: هاتف أندرويد يسحب الطابور ويرسل من باقة رسائلك (السكربت الجاهز: `public/relay-sms.sh` عبر Termux) |
| `OTP_MESSAGE_TEMPLATE` | اختياري: نص الرسالة مع `{code}` (أبقِه تحت 70 حرفاً) |

مدمجة فيه حمايات تلقائية: دقيقة انتظار بين كل طلبين لنفس الرقم، 8 رموز/ساعة لكل رقم، سقف عام 60/ساعة (يحمي رصيد المزود)، و10 محاولات دخول خاطئة/15 دقيقة (يمنع تخمين الرمز).
