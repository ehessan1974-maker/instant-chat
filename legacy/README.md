# 📦 النسخة القديمة (Legacy v1)

هذه هي النسخة الأصلية من المشروع كما كانت في المستودع، محفوظة للمرجعية والتاريخ فقط:

| الملف | الوصف |
|---|---|
| `server.js` | سيرفر Express 4 + WebSocket خام (مكتبة `ws`) + web-push — تخزين بالذاكرة فقط |
| `chat.html` | واجهة الويب القديمة (غرفة عامة، دخول بالاسم فقط) — نفس `public/index.html` سابقاً |
| `package.json` | تبعيات النسخة القديمة (express, ws, web-push) |
| `public/index.html` | نفس `chat.html` |
| `public/sw.js` | Service Worker القديم (كاش offline + إشعارات Push) |

## لماذا لم نطوّرها؟
1. كانت تستخدم `ws` خام بينما تطبيق الأندرويد يستخدم **Socket.IO** — أي أن الـ APK لم يكن يعمل معها أصلاً.
2. الرسائل والاشتراكات في الذاكرة — تضيع عند إعادة التشغيل.
3. مفاتيح VAPID كانت مكشوفة داخل الكود.

النسخة الجديدة (في جذر المستودع) تعالج كل ما سبق — انظر [`README.md`](../README.md) الرئيسي.

## تشغيل النسخة القديمة (إن أردت)
```bash
cd legacy
npm install
node server.js        # يعمل على PORT أو 3000
```
