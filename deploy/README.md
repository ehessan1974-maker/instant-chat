# 🚀 نشر «محادثة فورية» على سيرفر — رابط ثابت يعمل 24 ساعة

هذا الدليل يحوّل أي سيرفر فارغ (VPS) إلى برنامج محادثة كامل بـ **HTTPS تلقائي** —
جاهز للاستخدام الدائم من المتصفح، ومهيأ لتحويله لاحقاً إلى تطبيق APK
(الـ APK يحتاج رابط HTTPS ثابت ليعمل الميكروفون والكاميرا).

---

# 🆓 المسار المجاني (للتطوير والتجربة)

يوجد في الجذر **`Dockerfile`** يشغّل كل شيء في حاوية واحدة
(الواجهة + خادم الرسائل + وكيل Caddy) — يعمل على أي منصة Docker مجانية.

## أ) Render.com — الأسهل (يرتبط بـ GitHub مباشرة)

1. أنشئ حساباً مجانياً في https://render.com (بدون بطاقة)
2. **New +** ← **Web Service** ← اربط حساب GitHub ← اختر مستودع **instant-chat**
3. الإعدادات:
   - **Language/Runtime**: Docker (يكتشفه تلقائياً من `Dockerfile`)
   - **Instance Type**: Free
4. اضغط **Create Web Service** وانتظر البناء (~5-8 دقائق)
5. ستحصل على رابط ثابت مثل: `https://instant-chat-xxxx.onrender.com` ✅

## ب) Hugging Face Spaces — بديل مجاني

1. أنشئ حساباً في https://huggingface.co (مجاني، بدون بطاقة)
2. **New Space** ← الاسم `instant-chat` ← SDK: **Docker** ← Public
3. ارفع ملفات المشروع (ملف ملف أو عبر Git)
4. في إعدادات الـ Space تأكد من `app_port: 7860`
5. الرابط: `https://huggingface.co/spaces/اسمك/instant-chat`

## ⚠️ حدود الخطط المجانية (بصراحة)

| التخزين | مؤقت — **الرسائل والتسجيلات الصوتية تُمسح مع كل إعادة تشغيل** | مؤقت — نفس الأمر |
| الملاءمة | مرحلة بناء البرنامج وتجارب الأصدقاء | مرحلة بناء البرنامج وتجارب الأصدقاء |

> 🎯 عند اكتمال البرنامج وبدء الاستخدام الحقيقي: انتقل للسيرفر المدفوع
> (القسم التالي) — نفس الكود بدون أي تعديل، والبيانات تصبح دائمة.

## 📱 تحويل الرابط إلى APK مجاناً (بعد نشر الرابط)

البرنامج أصبح يوفر **manifest** وأيقونات PWA — أي يمكن حصره في APK عبر
**pwabuilder.com** (مجاني تماماً وبدون أدوات برمجة):

1. تأكد أن رابط موقعك يعمل بـ HTTPS
2. ادخل **https://www.pwabuilder.com** والصق رابطك
3. اضغط **Start** ← انتظر الفحص ← **Package for stores** ← **Android**
4. اضغط **Download** — ستحصل على ملف `signed.apk` جاهز للتثبيت والمشاركة

> ملاحظة: بدون ملف `assetlinks.json` سيظهر شريط عنوان المتصفح داخل التطبيق.
> هذا مقبول للبداية — وعند الاستقرار على الرابط النهائي أضف الملف ليصبح
> ملء الشاشة مثل واتساب تماماً (خطوة أرسلها لك عند الحاجة).

# 💼 المسار المدفوع الدائم (VPS — عند جاهزية البرنامج)

## 💰 الخطوة 0: تحتاج سيرفراً (VPS)

أي سيرفر بنظام **Ubuntu 22.04 أو 24.04** — يكفي 1GB ذاكرة (يُنصح 2GB):

| المزود | السعر التقريبي | ملاحظات |
|---|---|---|
| Hetzner | ~€4.5/شهر | ممتاز وسريع |
| Contabo | ~$5.5/شهر | ذاكرة أكبر بالسعر نفسه |
| DigitalOcean / Vultr | ~$6/شهر | سهلة للمبتدئين |
| Railway | ~$5/شهر | منصة جاهزة (لا تحتاج VPS لكن أغلى على المدى الطويل) |

> لا يوجد خيار «مجاني للأبد» حقيقي بدون بطاقة بنكية دولية —
> الاستضافة الدائمة بتكلفة قهوة شهرياً هي الحل العملي.

عند الشراء ستحصل على: **IP** (مثل `185.42.10.7`) و**كلمة سر root**.

---

## 🌐 الخطوة 1: اربط اسم النطاق (الدومين)

اختر واحدة من ثلاث:

**أ) دومين خاص** (الأفضل، من Namecheap أو Cloudflare بـ ~$1-10/سنة):
أضف سجل **A** يشير إلى IP السيرفر، وانتظر دقائق.

**ب) مجاني 2 دقيقة — DuckDNS:**
1. ادخل https://www.duckdns.org وسجّل بحسابك
2. أنشئ نطاقاً مثل `mychat` → يصبح `mychat.duckdns.org`
3. اكتب IP السيرفر في خانة current ip

**ج) للتجربة السريعة فقط — sslip.io:**
بدون أي تسجيل: استخدم `185.42.10.7.sslip.io` (IP بسلسلة sslip.io ملحقة)
> قد تصطدم بحدود معدل Let's Encrypt لأنها نطاق مشترك — للتجربة فقط.

## 🚀 الخطوة 2: النشر بأمر واحد

ادخل السيرفر (من أي جهاز):

```bash
ssh root@IP_السيرفر
```

ثم الصق هذا الأمر **كاملاً** (بدّل `mychat.duckdns.org` بدومينك):

```bash
curl -fsSL https://raw.githubusercontent.com/ehessan1974-maker/instant-chat/main/deploy/deploy-server.sh -o deploy.sh && sudo bash deploy.sh mychat.duckdns.org
```

انتظر 3-5 دقائق. سترى في النهاية:

```
✅ اكتمل النشر!
   رابط برنامجك:  https://mychat.duckdns.org
```

**افتح الرابط من أي جهاز — وشاركه مع أصدقائك. انتهى! 🎉**

> 🔒 ملاحظة أمنية: لا تشارك كلمة سر السيرفر مع أحد. إن أردت أن أنفّذ لك
> النشر كاملاً من هنا، أرسل لي IP وكلمة السر مؤقتاً في المحادثة، وبعد
> انتهائي غيّر كلمة السر فوراً بأمر `passwd`.

## 🔄 تحديث البرنامج لإصدار أحدث لاحقاً

```bash
ssh root@IP_السيرفر
curl -fsSL https://raw.githubusercontent.com/ehessan1974-maker/instant-chat/main/deploy/update.sh -o update.sh && sudo bash update.sh
```

التحديث **آمن تماماً**: لا يمس قاعدة البيانات ولا الرسائل ولا التسجيلات الصوتية.

## 🧰 أوامر الصيانة المفيدة

```bash
systemctl status instant-chat-web      # حالة الواجهة
systemctl status instant-chat-socket   # حالة خادم الرسائل
journalctl -u instant-chat-socket -f   # سجلات حية لخادم الرسائل
systemctl restart instant-chat-web     # إعادة تشغيل الواجهة
systemctl restart instant-chat-socket  # إعادة تشغيل خادم الرسائل
```

## 📱 تطبيق الأندرويد القديم (اختياري)

الـ APK القديم (`android/InstantChat.apk`) يتصل بالغرفة العامة عبر المنفذ 3003 مباشرة.
لتفعيله على السيرفر:

```bash
sudo ufw allow 3003/tcp
```

ثم في التطبيق أدخل عنوان الخادم: `دومينك.duckdns.org:3003`

> تطبيق APK الجديد (المستقبلي المبني على الواجهة الحالية) لا يحتاج هذا المنفذ —
> يستخدم HTTPS مثل المتصفح تماماً.

## 🗄️ نسخ احتياطي (يُنصح به)

كل بياناتك في ملف واحد — النسخ الاحتياطي سطر واحد:

```bash
tar czf backup-$(date +%F).tar.gz -C /opt/instant-chat db/
```

احتفظ بالملف في مكان آمن خارج السيرفر (حمّله لجهازك عبر `scp`).
